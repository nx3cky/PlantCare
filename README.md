# Plant Care

Кросплатформний застосунок-помічник для догляду за кімнатними рослинами (Flutter).
Каталог рослин із фото, інструкції з догляду та журнал виконаних процедур.

## Лабораторна робота №3
Базова структура застосунку та основні екрани за дизайном ЛР2 (без бізнес-логіки):
вхід, реєстрація, відновлення пароля, головна сторінка, профіль зі зміною пароля.

```
lib/
├── app/            маршрути
├── core/
│   ├── data/       hardcoded-дані
│   ├── theme/      кольори та тема Material 3
│   └── widgets/    перевикористовувані віджети
└── features/       auth, home, profile, shell
```

```bash
flutter pub get
flutter run
```
